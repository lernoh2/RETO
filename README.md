Gaming Redistributor Token Garetto G-ETTO_13V. An ERC777 token with an integrated redistribution mechanism in its structure.  In this version Chainlink VRF is implemented and the ecosystem has its own decentralized gambling platform. The token itself is not a a game or sort of gambling, this is a pure redistribution to reward holders for their activity. The tournament contracts significantly showcase the difference between gambling and redistribution. Contracts are not audited.
