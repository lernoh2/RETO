Gaming Redistributor Token Garetto G-ETTO_10V. An ERC777 token with an integrated redistribution mechanism in its structure. Not a game or sort of gambling, this is a pure redistribution to reward holders for their activity. In this version Chainlink VRF is implemented and the ecosystem has its own decentralized gambling platform. Contracts are not audited.
